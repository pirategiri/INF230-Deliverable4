## Overview

This project contains two tasks based on object-oriented programming in Python.

- Task 1: Temperature class with unit conversions and comparisons.
- Task 2: Fraction class with comparisons and special methods.

Both classes are tested using pytest.

## Project Files

- `temperature.py` - Temperature class.
- `temperature_test.py` - Tests for the Temperature class.
- `fraction.py` - Fraction class.
- `fraction_test.py` - Tests for the Fraction class.
- `submission.ipynb` - Notebook containing explanations and test results.
- `requirements.txt` - Required Python packages.

## Running Tests

Run all tests using:

`python -m pytest -v`
